A standalone GitHub-compatible git forge in one Node 22 process, standard library only: git smart HTTP (protocol v2 upload-pack, v0 receive-pack), the REST v3 API, GraphQL, and MCP from its own in-memory store. No UI, no database, no git binary, no outside service. Scores 120/120 conformance checks on the kit's local suite (feature 600, agent 200, perf ~137).

## Run it

```sh
node main.ts
```
